# Vietnamese-English Pronunciation Manual Test

Purpose: exercise Vietnamese pronunciation variants and record raw vs normalized results.

Profiles:
- General Vietnamese English
- Southern Vietnamese English
- Mekong Delta Vietnamese English
- Mixed / Unknown (default)

Each script should be read aloud by a speaker and the operator should record:
- raw recognition
- normalized result
- correction type (automatic / suggestion / ignored)
- operator decision
- microphone
- environment
- speaker identifier (optional label)
- notes

Scripts (Southern / Mekong should include these terms):
- S G A, SGAs, ess gee ayz
- roadmap, road map, rô map
- Cohort 2, co host two
- pain point, painpoint
- Design Thinking, customer insight, business model
- prototype, validation, pitch deck, incubatee, product-market fit, churn, growth strategy, go-to-market

Do not record any sensitive demographic information.
